[자동동기화 해제 및 수동 동기화 전환 내역]
버전: 20260730-9-manual

1. 자동 동기화 해제
- 일정/할 일/메모/D-Day 변경 시 자동 업로드/자동 병합 동기화가 실행되지 않도록 수정했습니다.
- 기존 자동 동기화 활성화 플래그를 localStorage에서 제거하도록 처리했습니다.
- 사이트 실행/화면 복귀/온라인 복귀/30초 주기 자동 동기화 루프를 제거했습니다.

2. 수동 동기화 방식으로 복귀
- [클라우드 업로드], [클라우드 불러오기], [병합 동기화] 버튼은 유지했습니다.
- 사용자가 직접 버튼을 누를 때만 GitHub Gist와 통신합니다.
- 로컬에서 일정을 수정해도 자동으로 클라우드에 올라가지 않습니다.

3. 1번/2번 사이트 데이터 섞임 방지
- 2번 사이트는 scheduler_hyunji 전용 Gist 파일만 읽도록 강화했습니다.
- 같은 Gist ID를 실수로 입력하더라도 2번 사이트가 1번 사이트의 scheduler-data.json을 불러오지 않도록 했습니다.
- 그래도 안정성을 위해 1번 사이트와 2번 사이트는 서로 다른 Gist ID 사용을 권장합니다.

4. 공휴일 보정 유지
- 크리스마스 명칭 정규화, 제헌절 보정, 설날/추석 보정은 유지했습니다.

[권장 조치]
1. 배포 전 현재 로컬 데이터 백업 JSON을 한 번 다운로드하세요.
2. 1번 사이트와 2번 사이트의 Gist ID를 서로 다르게 설정하세요.
3. 이미 섞인 Gist가 있다면, 각 사이트에서 올바른 로컬 데이터 상태를 확인한 뒤 각각의 Gist에 [클라우드 업로드]를 수동 실행하세요.
4. 배포 후 Ctrl + F5로 강력 새로고침하세요.
