1. 일정 목록 일괄 삭제 기능 추가
- 달력에서 날짜를 클릭해 열리는 일정 목록에서 체크박스로 여러 일정을 선택한 뒤 한 번에 삭제할 수 있습니다.
- 반복 일정은 선택한 날짜의 해당 회차만 제외 처리되도록 했습니다.

2. 업무 리스트 일괄 삭제 기능 추가
- 업무 리스트 상단에 전체 선택, 선택 해제, 선택 삭제 버튼을 추가했습니다.
- 현재 필터 화면에 보이는 업무를 기준으로 선택 삭제할 수 있습니다.

3. 정보 메모 일괄 삭제 기능 추가
- 메모 목록 상단에 전체 선택, 선택 해제, 선택 삭제 버튼을 추가했습니다.
- 선택한 메모가 현재 열려 있는 메모이면 삭제 후 편집창을 초기화합니다.

4. D-Day 일괄 삭제 기능 추가
- 대시보드의 중요 일정 D-Day 목록에서도 여러 항목을 체크해 한 번에 삭제할 수 있습니다.

5. 기존 기능 유지
- 자동동기화 해제 및 수동 업로드/불러오기 방식 유지
- 1번/2번 사이트 데이터 분리 구조 유지
- 크리스마스/제헌절/설날/추석 공휴일 보정 유지

- 삭제 전 필요한 경우 JSON 백업을 먼저 내려받으세요.
